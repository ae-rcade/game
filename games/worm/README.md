# 블랙맘바 (지렁이 게임)

먹이를 먹고 길어지는 지렁이 게임. 지금은 **2단계(맵 하나를 여러 명이 함께)** 예요.
주소 끝에 `?ping`을 붙이면 서버를 다녀오는 시간이 보여요.
`config.json`의 `serverUrl`이 비어 있으면 서버 없이 혼자(상대는 봇) 하고, 서버 주소를 넣으면 함께 해요.
서버 설정은 [server/README.md](server/README.md)를 봐 주세요.

## 규칙

- 화면을 끌면 그 방향으로 가고, 빠르게 두 번 터치하면 1초 부스트(끝난 뒤 2초 대기)
- 먹이를 먹으면 그 캐릭터 색의 마디가 꼬리에 붙어요.
- 머리가 다른 지렁이 몸이나 맵 끝에 닿으면 죽어요. 내 몸은 지나갈 수 있어요.
- 머리끼리 부딪히면 짧은 쪽이 죽어요(같으면 둘 다).
- 죽은 몸은 같은 색의 큰 먹이가 돼요. 시작 직후 2초는 보호돼요.
- 맵 둘레의 검은 독사는 장식이에요. 머리는 160초에 한 바퀴 돌고, 닿는 판정은 맵 가장자리 그대로예요.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `rules.js` | 속도·맵 크기·봇 수 같은 숫자와 색 |
| `world.js` | 이동, 먹기, 충돌 (화면 코드 없음) |
| `bots.js` | 컴퓨터 지렁이 |
| `sprites.js` | 도트 지렁이 그림 만들기, 먹이 그림 불러오기 |
| `render.js` | 맵·지렁이 그리기 |
| `border.js` | 맵 둘레의 검은 독사 그리기 |
| `input.js` | 끌기, 두 번 터치 |
| `main.js` | 입장 → 플레이 → 다시 시작 |
| `local.js` | 혼자 하기, 시작 전 배경 |
| `online.js` | 서버 접속, 받은 상태를 부드럽게 이어 보여 주기 |
| `predict.js` | 내 지렁이를 바로 움직이고 서버 위치에 맞추기 |
| `protocol.js` | 화면과 서버가 주고받는 형식 |
| `config.json` | 서버 주소 |
| `server/` | Cloudflare 서버 |

`rules.js`·`world.js`·`bots.js`·`protocol.js`는 서버도 함께 써요. 고치면 서버도 다시 배포돼야 해요.

## 게임 카드 그림

`icon.png`(투명 배경). 수박 게임 폴더의 `블랙맘바 픽셀.png`에서 체크무늬 배경을 지워 만들었어요.

## 먹이 그림 바꾸기

`images/food1.png` ~ `food10.png`(10번은 레몬)(투명 배경 정사각형)를 같은 이름으로 올리면 바뀌어요.
수박 게임 폴더의 그림을 복사해 둔 것이라 수박 게임 그림을 바꿔도 여기는 그대로예요.
몸 색은 `rules.js`의 `KINDS`에서 같은 순서로 고쳐요.
