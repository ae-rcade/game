# 가사 맞추기

가사를 보고 노래 제목을 맞히는 게임이에요. 지금은 **싱글 모드**(150초 타임어택)만 있어요.

## 규칙

- 노래의 가사에서 **이어지는 4칸**을 무작위로 골라요. 마지막 칸은 항상 4번째로만 나와요.
- 가사에 들어 있는 제목과 `정답인정` 표기는 `●●●`로 가려요. 시트에 적지 않은 줄임말·변형은 가려지지 않아요.
- 처음에는 1·2번째 줄이 보이고, 나머지는 `?` 칸이에요. 칸을 눌러 차례로 열어요.
- 3번째 줄은 문제가 나온 뒤 5초, 4번째 줄은 3번째를 연 뒤 5초 후에 열 수 있어요.
- 점수는 2줄까지 100점, 3줄 60점, 4줄 20점이고, 틀리면 -20점이에요(총점이 음수가 될 수 있어요).
- 패스는 가사를 모두 연 뒤에 가능하고 감점이 없어요.
- 정답·오답·패스 후에는 정답을 1.2초 보여주고 다음 문제로 넘어가요. 이때 남은 시간은 멈춰요.

## 문제 올리기 (구글 스프레드시트)

1. 구글 드라이브에서 새 스프레드시트를 만들어요. `sample.csv`를 **파일 → 가져오기**로 넣으면 양식이 생겨요.
2. 첫 줄은 열 이름이에요. 예시 줄은 지우고 한 줄에 한 문제씩 입력해요.

   | 제목 | 정답인정 | 가수 | 가사1 | 가사2 | 가사3 | 가사4 |
   |---|---|---|---|---|---|---|
   | 필수 | 선택: 다른 표기, 여러 개는 `\|`로 구분 | 선택 | 가사 첫 줄 | 둘째 줄 | 셋째 줄 | 계속 → |

   - 노래의 가사를 순서대로 `가사1`부터 오른쪽으로 채워요. `가사5` 이후의 열 이름은 비워 둬도 돼요.
   - 한 칸이 한 줄이에요(칸 안의 줄바꿈은 그대로 보여요). 4칸보다 적으면 있는 칸만 나와요.
   - 가사 오른쪽 칸에 메모를 적으면 가사로 인식돼요.
   - `가수`가 `예시 문제`인 행은 게임에 나오지 않아요.
   - 대소문자·띄어쓰기·문장부호는 판정에서 무시해요. 제목의 괄호 부분은 빼고 써도 정답이에요.
   - 영어 제목을 한글로 써도 맞게 하려면 `정답인정`에 한글 표기를 적어요.
3. **파일 → 공유 → 웹에 게시** → 문제가 있는 시트 선택 → 형식 **쉼표로 구분된 값(.csv)** → **게시**
4. 나온 주소를 `config.json`의 `sheetUrl`에 넣고 커밋해요.

```json
{ "sheetUrl": "https://docs.google.com/spreadsheets/d/e/…/pub?gid=0&single=true&output=csv" }
```

시트를 고치면 몇 분 뒤 게임에 반영돼요. `sheetUrl`이 비어 있으면 `sample.csv`의 창작 예시 문제가 나와요.

## 주의

- 게시한 주소는 누구나 열 수 있고, 게임 화면에서도 확인할 수 있어서 정답을 완전히 숨길 수 없어요.
- 노래 가사는 저작권이 있어요. 이용 허락을 받은 범위에서 사용하고, 가사를 이 공개 저장소의 파일에는 넣지 마세요.
- 시트에 개인정보를 넣지 마세요.
